## Descripción
Programa que recibe la ruta de una imagen .bmp con figuras geométricas de
colores sólidos y regresa, para cada figura, su color en hexadecimal y su categoría (C: cuadrados, T: triángulos, O: círculos, X: otros).

## Requisitos
- Python 3
- OpenCV y NumPy

## Instalación
```
pip install opencv-python numpy
```

## Uso
Desde la raíz del repositorio:
```
python src/main.py bancoDeImg/captura_01.bmp
```
O si estás parado dentro de `src/`:
```
python main.py ../bancoDeImg/captura_01.bmp
```
